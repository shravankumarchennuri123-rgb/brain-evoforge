# BRAIN-EvoForge Knowledge Layer

This directory is the research-intelligence corpus boundary.

## Source hierarchy

Lower numeric authority is stronger:

1. `live_brain` — directly observed from the authenticated BRAIN account.
2. `worldquant_official` — official WorldQuant/BRAIN documentation and official publications.
3. `academic` — peer-reviewed or otherwise established quantitative-finance literature.
4. `community` — practitioner observations and community material.
5. `unverified` — claims without adequate independent support.
6. `llm_generated` — hypotheses or summaries generated by a model; never treated as evidence.

Source authority and research usefulness are separate concepts. An official source can explain platform behavior without proving that a particular alpha mechanism works.

## Knowledge records

Knowledge is stored as atomic records rather than one large prose summary.

Each record preserves:

- the source that supports it;
- the topic and claim;
- optional implementation details;
- confidence;
- source locator;
- extraction and verification timestamps;
- whether the claim has been verified against live BRAIN behavior.

## Repository layout

```
knowledge/
├── sources/       # source inventory and metadata
├── brain/         # extracted BRAIN platform knowledge
├── literature/    # extracted academic research
├── concepts/      # normalized mechanisms and hypotheses
├── mappings/      # research concept -> BRAIN fields/operators
└── provenance/    # extraction and verification logs
```

The first implementation stores structured metadata locally in JSON. Raw copyrighted material should remain at its lawful source; the project should store concise derived knowledge, provenance, identifiers, and links rather than indiscriminately copying full texts.
